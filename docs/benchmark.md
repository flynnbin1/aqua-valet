## Findings & discrepancies the build must handle

1. **`/your-feedback/` is a 404 on the live site** (noindex 404 template). The
   sitemap-plan marks it KEEP — building it new is pure upside (nothing ranking
   to protect), but it is *not* currently a live URL. Confirm with Niall whether
   it ever existed / has backlinks before treating it as an SEO-critical KEEP.
2. **The homepage has no H1 at all.** "Corks Most Professional Valeting Service"
   is an **H2** on the live page (other homepage H2s: "Latest Valet Deals",
   "What our Customers Have to Say", "Auto Care At Your Doorstep", "Schedule a
   Service"). CLAUDE.md rule 3 still applies to the wording — the new site
   promotes it to a proper H1 with evolved (not replaced) keywords.
3. **Homepage title tag** is exactly `Aqua Valet Cork | Professional Car
   Valeting & Wash` — matches CLAUDE.md rule 3. Evolve, never replace.
4. **The homepage meta description advertises "from only €10"** — must NOT be
   carried over (CLAUDE.md rule 4). Same for the `/book-now/` title
   ("Car wash €10 | MPV Wash €12") — the URL is KEEP but title/description must
   be rewritten around the enquiry flow, keeping "Book"/"Cork" keywords.
5. **Misspelled internal links exist on the old site**: `/sevices/car-wash/`,
   `/sevices/car-valeting/`, `/sevices/pickup-mobile-valeting/` (missing "r").
   WordPress currently rescues them with a canonical redirect to the correct
   `/services/...` URLs. Add these to the 301 map so they keep resolving.
6. **Bare (no-trailing-slash) variants** `/book-now`, `/services`,
   `/valeting-work` are linked internally; the new site must redirect or
   serve them consistently to the trailing-slash canonical.
7. **`/contact/` description says "open Monday to Saturday"** — wrong. New site
   states Wednesday, Friday, Saturday only (matches GBP).
8. **`/booking-approval/` and `/booking-cancellation/`** are live, indexable
   Bookly pages with no meta descriptions. Obsolete under the new enquiry flow —
   301 both to `/book-now/`.
9. **robots.txt returns 403 Forbidden** on the live server (LiteSpeed block).
   Effectively no robots.txt. The new preview deployments must serve a real
   robots.txt with `Disallow: /` until launch.
10. **Old sitemap.xml** contains only pages (no products) and `sitemap.html`.
    New site regenerates a proper sitemap.xml per wave — submitted only at launch.
11. **Yoast schema present sitewide**: WebSite + Organization (logo
    `aqua-valet-cork.png`, sameAs Facebook + X profiles). The new site's
    LocalBusiness (CarWash) schema should keep the `sameAs` links:
    `https://www.facebook.com/aquavaletcork/`, `https://x.com/AquaValetCork`.
